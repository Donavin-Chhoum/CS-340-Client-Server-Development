## How do you write programs that are maintainable, readable, and adaptable? Especially consider your work on the CRUD Python module from Project One, which you used to connect the dashboard widgets to the database in Project Two. What were the advantages of working in this way? How else could you use this CRUD Python module in the future?

When writing programs, I try to follow standard coding practices. I try to make sure that the naming conventions of my classes, variables, and methods are relevant for their use cases. Formatting and the layout of the code ensures that readability is easy for both myself and people viewing the code for the first time. Comments are used to briefly explain the purpose of sections of the code. The advantages of working this way is that it makes working with and understanding the code easier. The readability makes it easier to navigate and find specific sections easier while naming conventions ensure you know exactly what purpose specific objects and methods serve. Even if the naming convention doesn't tell you what you need to know, the added comments will supplement that.

The first thing that I typically do when approaching a problem is breaking down the requirements into smaller parts. This helps give me a clear picture of what is required of me and I can work on each requirement individually. For example, when creating the CRUD Module, I could focus on each operation of CRUD without worrying about the other operations.\
\
My approach to this project differed from previous assignments because most previous assignments that I had dealt with a clearly defined problem. Project 2 had me working with real-world data and problems that I had to make a decision on. For example, the three interactive filters has a list of predefined breeds, but for breeds such as "German Shepherd", there exists mix breeds and cross breeds such as "German Shepherd/Labrador Retriever". ## What do computer scientists do, and why does it matter? How would your work on this type of project help a company, like Grazioso Salvare, to do their work better?

Computer scientists turn data and ideas into tools that people can use to solve problems. The idea starts with wanting to solve a problem, then a solution needs to be designed. After the design in completed, we can build it, test it, and document it so the tool can be understood and maintained easily. This matters because most organizations have far more data than anyone can feasibly review by hand. A well built system that can organize and filter that data for you is extremely valuable in supporting decisions.\
\
This type of work greatly benefits Grazioso Salvare because the shelter data holds thousands of records which includes both dogs and cats. Sorting and filtering this data manually would take a long time. With the dashboard that I created in Project 2, the hard work is done by the system and when the dataset is updated with more records, those records will also work with the current system. This allows the company to spend less time searching the records and more time evaluating and training dogs.
